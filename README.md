# 🏰 古域魔陣：守護神殿 (Ancient Arcane Bastion) v1.2.0

一款結合**「踏上地下 Logo 投幣升級 / 擴張領地」**廣告爽感玩法與**「古代 + 魔法 RPG 10 小時深度養成」**的 HTML5 手機 WebApp 守城遊戲。

## ✨ 核心特色
1. **100% 還原並超越廣告核心玩法**：
   - 操控英雄踏上地面的發光魔陣 Logo，金幣與魔力水晶會以**拋物線飛入魔陣**，跳動扣除頭頂氣泡數字！
   - **18 座互動地下魔陣**橫跨 **4 大可擴張領地**：
     - **神像建造與五階進化**：寒冰賢者神像、黃金戰錘泰坦、烈焰魔神雕像、北境紫電劍聖、星隕魔導巨砲、亡靈古墓碑、太古金龍神座、虛空黑洞碑。
     - **領地擴建 (`EXPAND`)**：踏上擴建魔陣解開北境山崖、東翼星辰防線、深淵龍魂聖域封印！
     - **特殊功能魔陣**：聖殿金脈工坊（派遣採集精靈）、太古魔力晶泉、城牆銘刻修復陣、遠古鐵匠神爐（直接鍛造掉落裝備）、天罰元素神龕（全屏流星雨）、皇家傭兵營、時空魔王召喚陣。
2. **10 小時長線 RPG 養成系統**：
   - **5 大古域戰役章節 (250 波主線 + 無盡深淵)** + **太古神殿轉生 (Ascension Rebirth)**。
   - **4 大可切換英雄職業**：符文聖劍士、時空大魔導、烈陽聖騎士、幻影獵魔人。
   - **聖物裝備鍛造與一鍵三合一升階**：武器、聖甲、魔戒、古聖物四部位 × 六大稀有度。
   - **18 節點太古星盤天賦樹**、**15 階段主線任務**、**離線掛機收益 (最高 10 小時)** 與 **跨裝置存檔碼匯出/匯入**。
3. **專為手機 WebApp 與 GitHub Pages 打造**：
   - 支援手機單手**虛擬搖桿拖曳**、**點擊地面/魔陣自動導航**、以及 **三段式 AI 自動巡邏/自動踏陣升級**。
   - 內建 `manifest.json` 支援 iOS Safari / Android Chrome「加入主畫面」全螢幕遊玩。

## 🚀 GitHub Pages 部署指南
1. 將壓縮包解壓縮後的所有檔案（`index.html`, `css/`, `js/`, `assets/`, `manifest.json`, `.nojekyll`）上傳至你的 GitHub Repository 根目錄。
2. 前往 GitHub Repository -> **Settings** -> **Pages**，在 **Build and deployment** 選擇 `Deploy from a branch` 並選擇 `main` / `/(root)`。
3. 等待約 1 分鐘後，即可透過手機開啟 `https://<你的帳號>.github.io/<倉庫名稱>/` 暢玩！
